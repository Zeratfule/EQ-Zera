Bug reports, feature requests, questions

Every message lands in the author's inbox. For a bug, the most useful report says what you did, what you expected, what happened instead, and which version you are on (Preferences shows it). If a log line matters, paste it; the app's own Send feedback dialog can attach a scrubbed log slice for you.

GitHub issue

Best for bugs: it stays public, others can add to it, and you can follow the fix. Open an issue.

From inside the app

Send feedback in the nav drawer fills in your version and can attach a log slice you review first.
